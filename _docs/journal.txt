Session 3

What I did
- I created the two main data validation documents: the Engineering Department Validation & Data Ingestion Handoff Summary 
and the SkillCorner Acquisition, Structure, and Validation Report. These documents explained what was found during the first 
real validation work on the SkillCorner dataset and helped me understand what the data actually looks like before building 
anything on top of it.

- The biggest things I went over were the match file structure, how the tracking JSONL files work, how player metadata 
connects to tracking data, and what files exist for each match. I also reviewed the important issue that one match is missing 
dynamic events, so future ingestion code needs to treat dynamic events as optional instead of assuming every match has them.

- I also went over the major validation findings, especially that tracking player_data.player_id should join to 
players_df["id"], not trackable_object or team_player_id. I reviewed how usable tracking frames seem to be either empty 
or full 22-player frames, which is much cleaner than expected. The documents also showed that the phases of play and 
dynamic event windows align properly with tracking frames, which is important because the project depends on phase-based 
tactical analysis later.

Why this mattered
- This session helped move the project from “I have the data downloaded” to “I understand the data well enough to start 
building ingestion code.” It also made clear that the next step should not be tactical metrics or AI interpretation yet. The 
next step should be turning the validation findings into reusable loading and validation modules.

Key decisions
- Treat the validation docs as the main reference for Layer 1 data ingestion
- Use SkillCorner as the first validated dataset
- Join tracking player_id to players_df["id"]
- Treat dynamic events as optional because one match is missing that file
- Preserve is_detected for future confidence and quality checks
- Filter early tracking work to usable 22-player frames
- Use phases of play as an important segmentation source later
- Move next toward reusable ingestion engineering before tactical metrics
- Known limitation: match 1953632 has no dynamic_events.csv file.
